# 眼底数据集与病种速查

| `data` 下的目录 | 主要疾病或任务 | 本地有哪些标注 |
| --- | --- | --- |
| [APTOS2019](./APTOS2019/README.md) | 糖尿病视网膜病变（糖网，DR） | 每张照片有一个糖网等级，范围为 0–4 级，0 级表示无糖网。 |
| [DDR](./DDR/README.md) | 糖网分级、病灶检测与分割 | 糖网 0–4 级，标签 5 表示图像不可分级。部分图还标出了微动脉瘤、出血、硬性渗出和软性渗出。 |
| [IDRiD](./IDRiD/README.md) | 糖网、糖尿病性黄斑水肿风险 | 分别标注糖网严重程度和黄斑水肿风险，另有病灶分割、视盘和黄斑中心凹定位标注。 |
| [PAPILA](./PAPILA/README.md) | 青光眼筛查 | 每眼标为正常、疑似青光眼或青光眼，另有两位专家勾画的视盘、视杯轮廓。 |
| [REFUGE](./REFUGE/README.md) | 青光眼相关的视盘、视杯分割 | 本地 1,200 张图都有盘杯掩膜。其中 400 张训练图可按文件名前缀区分青光眼与非青光眼。 |
| [RFMiD](./RFMiD/README.md) | 单眼多种疾病和异常 | 有 45 个疾病或体征标签，另有总体异常标记。常见例子有糖网、年龄相关性黄斑变性（AMD）、近视性眼底改变、视网膜静脉阻塞、玻璃膜疣和视盘凹陷。 |
| [RFMiD2](./RFMiD2/README.md) | 单眼多种疾病和异常的补充集 | 含糖网、AMD、近视性眼底改变，也收录视网膜脱离和脉络膜新生血管等。本项目的分组多标签任务用它做外部测试。[原始标签释义](https://www.mdpi.com/2306-5729/8/2/29) |
| [ODIR-5K](./ODIR-5K/) | 患者双眼联合的八标签分类 | 正常（N）、糖尿病（D）、青光眼（G）、白内障（C）、AMD（A）、高血压（H）、近视（M）、其他疾病或异常（O）。这八项标在患者层面。[官方标签定义](https://odir2019.grand-challenge.org/dataset/) |
| [FIVES](./FIVES/README.md) | 视网膜血管分割 | 每张图有血管掩膜，也有图像质量标注。图像来自正常、糖网、AMD、青光眼四组。 |
| [EyeQ](./EyeQ/README.md) | 眼底图像质量评估 | 质量分为良好（Good）、可用（Usable）、拒收（Reject）。原始标注表另附糖网等级。 |

[prepared](./prepared/README.md) 是上述 10 个数据集的整理目录，存放训练、验证和测试清单，以及派生的掩膜和裁剪图。
