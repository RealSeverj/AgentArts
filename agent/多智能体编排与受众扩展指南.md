# 华为云 AgentArts 多智能体编排与三层受众扩展指南

本指南用于将本项目从已验证的“A0 全功能单智能体”无缝升级或配置为比赛正式要求下的 **“A1 主控导诊 + A2 医学解读 + A3 随访分诊 + A4 历史对比与大众科普” 多智能体协同架构**，同时不依赖外部 PDF 文档。

---

## 一、两种部署模式与适用场景

| 模式 | 适用阶段 | 资产组成 | 导入/创建方式 |
| :--- | :--- | :--- | :--- |
| **模式 A：单智能体全能基线 (`A0`)** | 个人快速联调、稳定线上主通道 | `agent_fundus.jsonl`（内置 6 个 API 工具 + `A0` 提示词） + 平台知识库 | 在 AgentArts **一键导入** `agent/agent_ready_severj/agent_fundus.jsonl`，发布插件后即可对话测试 |
| **模式 B：多智能体协同版 (`A1 + A2 + A3 + A4`)** | 比赛正式演示、分工溯源与角色隔离 | 1 个中央控制器（`A1`）+ 3~4 个专业子智能体/子工作流（`W20/W30/W40/W60`）+ 共享 6 工具插件 + 4 份知识文档 | 复用模式 A 导入的 `Retin_ScreeningAndFollow_up` 插件与 `眼底筛查医学知识库`，在 **开发中心 → 智能体管理 → 多智能体** 装配 |

## 二、华为云平台侧分步配置流程

### 第 1 步：更新平台知识库（支持大众体检与慢病护眼扩展）
1. 进入华为云 AgentArts **托管与运行 → 知识库 → 眼底筛查医学知识库**。
2. 确保已上传全部 4 份最新文档（见 `knowledge_base/`）：
   - `01_标签字典与体征边界.md`
   - `02_糖网分期与专病随访依据.md`
   - `03_眼科急症警示症状与筛查边界.md`
   - `04_大众体检与慢病护眼科普.md`（新增：三层受众、良性体检词去焦虑、慢病管理与无图分诊）
3. 检索模式保持 **混合检索（语义 + 关键词）**，`TopK = 5`。

### 第 2 步：刷新 API 插件（复用最新 6 工具 Schema）
1. 在项目根目录执行以下命令重新生成最新导出包（已自动嵌入本机 API Key、`https://severj.top` 域名与 A0~A4 提示词）：
   ```powershell
   Remove-Item -Recurse -Force .\agent\agent_ready_severj
   C:\Users\Severj\anaconda3\envs\py310\python.exe .\agent\prepare_agent.py --origin https://severj.top --output .\agent\agent_ready_severj --embed-local-key
   ```
2. 若需只刷新单智能体 `A0`，直接在平台导入 `agent_fundus.jsonl` 并覆盖或重新绑定插件、发布版本即可。
3. 若构建多智能体应用，各子工作流或子智能体均共用同一个已发布插件中的 6 个工具：
   - `screen_fundus`（支持原子绑定 `eye`、`symptoms`、`history`）
   - `get_context`
   - `get_assessment`
   - `record_intake`
   - `evaluate_care`
   - `compare_assessments`

### 第 3 步：创建多智能体（Multi-Agent）节点分工
在 **开发中心 → 智能体管理 → 多智能体 → 创建多智能体** 中按下列清单建立角色分工（提示词原文均位于 `agent/prompts/`）：

1. **中央控制器 `A1 主控导诊`**（入口节点）
   - 提示词：`agent/prompts/A1_主控导诊提示词.txt`
   - 挂载工具：`get_context`、`screen_fundus`、`record_intake`
   - 路由职责：
     - **紧急性强拦截**：文本命中飞蚊/闪光/幕帘/骤降/剧痛时，无论有图无图立即交由 `A3` 触发急诊提示；
     - **受众识别**：识别用户属于“大众体检受检者 (`patient`) / 陪诊家属 (`caregiver`) / 基层医生 (`clinician`)”，写入会话上下文传递；
     - **新图原子筛查**：收到眼底图及随图眼别症状时，直接调用 `screen_fundus` 一次性原子入库，获取 `assessment_id` 后交给 `A2`。

2. **子流程 / 子智能体 `A2 医学解读问答`（对应 `W20`）**
   - 提示词：`agent/prompts/A2_医学解读问答提示词.txt`
   - 挂载工具：`get_assessment` + 挂载知识库 `眼底筛查医学知识库`
   - 职责：严格只读 `EvidencePacket` 与知识库 `[SRC_*]` 片段，完成质控判断、四类标签概念边界区分、三层受众语态解读、无图体检单名词答疑，并展示原图/标注图与在线 PDF 报告链接。

3. **子流程 / 子智能体 `A3 随访与急症分诊`（对应 `W30`）**
   - 提示词：`agent/prompts/A3_随访管理提示词.txt`
   - 挂载工具：`record_intake`、`evaluate_care` + 挂载知识库 `眼底筛查医学知识库`
   - 职责：同步问询状态并运行确定性规则引擎，严格遵守急症优先红线（`[RULE_URGENT_SYMPTOM_01]`），每轮克制追问 1~2 项缺失信息，输出结构化就医优先级、复查时间、诊前准备清单与实时同步的报告链接。

4. **子流程 / 子智能体 `A4 历史对比与大众科普`（对应 `W40 / W60`）**
   - 提示词：`agent/prompts/A4_对比与科普教育提示词.txt`
   - 挂载工具：`get_context`、`get_assessment`、`compare_assessments` + 挂载知识库 `眼底筛查医学知识库`
   - 职责：执行同眼历史纵向比较（严禁 `unknown` 互相匹配、严禁把分类分数差写成进展）、生成左/右眼并列对照表，并承担体检良性名词去焦虑与糖尿病/高血压护眼科普。

## 三、三层受众与扩展场景推荐测试用例

在控制台预览调试或集成演示工作台 `/v1/demo` 中，建议重点验证以下 4 组覆盖广泛受众的对话用例：
1. **用例 1（慢病双图原子建档 + PDF 导出）**：先发左眼糖网图并说明“左眼，患糖尿病 8 年，目前看东西有点雾”，再发右眼正常对照图并说明“右眼，目前没特殊感觉”，核对双图报告中左右眼各自独立绑定、无错位，且可正常导出 A4 PDF。
2. **用例 2（急症红线强拦截）**：补充输入“我右眼今天突然眼前出现大量黑影飘动，还一闪一闪的”，验证即便右眼照片本身模型未报错，系统仍第一时间给出 **立即眼科急诊评估** 与 `[RULE_URGENT_SYMPTOM_01]` 依据。
3. **用例 3（大众体检去焦虑 + 无图咨询）**：不传图直接提问“我妈妈体检单写着豹纹状眼底（TSLN）和玻璃膜疣（DN），陪她去眼科复查要带什么东西？会立刻失明吗？”验证 `A2+A4` 通俗定心解读与家属陪诊四步清单，且严禁给出“绝对正常”承诺。
4. **用例 4（同眼历史对比边界拦截）**：测试先比对两张已知为 `unknown` 眼别的记录（应被规则拦截并提示先确认眼别），再绑定明确同一眼别后验证 `compare_assessments` 返回可比结果并附注得分差异含义说明。
