# 华为云 AgentArts 双应用（患者端 + 医生端）多智能体编排指南

本系统采用**院内影像同步 + 医患双端分离**设计，在华为云 AgentArts 平台按 **方式 1** 分别装配两个独立的多智能体应用，并全部采用 **单入参 `query` Dify `0.6.0` 工作流**，彻底规避“参数提取原子能力调用失败”。

---

## 一、两大平台应用与工作流装配清单

### 应用一：`视健康-患者端管家`
- **工作流文件所在目录**：`agent/agent_ready_severj/dify_workflows/patient/`（外加根目录通用 `W90_通用兜底引导.yml`）
- **核心设计原则**：患者免上传眼底照片，报出手机号后自动关联院内档案；报告解读使用温暖亲切的日常用语；突发不适结合本人慢病史与既往眼底底子优先拦截。

| 控制器槽位 | 导入工作流文件名 | 控制器意图路由说明 / 职责 |
| :--- | :--- | :--- |
| **起始工作流** | `P00_患者身份与档案绑定.yml` | （每轮必先执行）从对话提取或复用手机号，同步患者档案与新拍片状态，给予温暖欢迎 |
| **子工作流 1** | `P10_患者报告温暖解读.yml` | 患者询问最新报告、右眼/左眼检查情况或病情有没有好转（自动测新片+对比+患者版 PDF 链接） |
| **子工作流 2** | `P20_结合病史症状问诊.yml` | 患者反映突然出现飞蚊黑影、闪光、模糊、眼痛等不适，需要结合其既往糖尿病/眼底底子分诊 |
| **子工作流 3** | `P30_眼健康日常科普答疑.yml` | 患者日常询问青光眼、糖网、豹纹状眼底、玻璃膜疣等病因及日常护眼注意事项 |
| **默认工作流** | `W90_通用兜底引导.yml` | 超出眼科与眼健康范围时的礼貌边界说明 |

> **视频与资讯 MCP 扩展位置**：在 `P30_眼健康日常科普答疑.yml` 的画布中，您可以直接把华为云市场接入的视频搜索/资讯搜索插件或 MCP 节点串联在 `kb_edu` 之后、`llm_edu` 之前，实现真实科普文章与视频卡片推荐。

### 应用二：`视健康-医生端辅助诊断`
- **工作流文件所在目录**：`agent/agent_ready_severj/dify_workflows/doctor/`（外加根目录通用 `W90_通用兜底引导.yml`）
- **核心设计原则**：医生按会诊患者手机号接诊，系统列出左/右眼院内待分析及已分析状态；医生指令后自动拉取最新院内影像执行六模型与四类病灶分割推理，输出临床风险提示、医学依据与临床版 PDF 报告。

| 控制器槽位 | 导入工作流文件名 | 控制器意图路由说明 / 职责 |
| :--- | :--- | :--- |
| **起始/接诊工作流** | `D00_会诊患者接诊与影像概览.yml` | 医生输入患者手机号时触发（您正在会诊：xxx，当前已拍摄左眼/右眼） |
| **子工作流 1** | `D10_院内影像辅助诊断.yml` | 医生要求对会诊患者左眼/右眼执行辅助诊断（六模型+病灶定位+指南依据+医生版 PDF 报告） |
| **子工作流 2** | `D20_患者报告调阅与对比.yml` | 医生要求调出某患者左/右眼既往或最新归档临床报告 |
| **默认工作流** | `W90_通用兜底引导.yml` | 非接诊、越界问题时的默认引导 |

## 二、华为云平台五步上线流程

1. **导入 5 份医学与科普知识库**：进入 **托管与运行 → 知识库 → `眼底筛查医学知识库`**，上传 [knowledge_base/](file:///e:/Developer/Competition/AgentArts/knowledge_base) 下全部 5 份 Markdown 文档（含新增 `05_常见眼病日常科普问答_患者亲切版.md`），检索模式设为 **混合检索（TopK = 5）**。
2. **导入工作流（Dify `0.6.0`）**：进入 **工作流 → 导入 DSL**，上传 `agent/agent_ready_severj/dify_workflows/` 下的 `.yml` 文件（已内置 `https://severj.top` 与本机 `X-API-Key`，且开始节点只有 1 个平台默认的 `query` 入参）。
3. **画布重绑与发布**：在每个工作流画布中重选您的平台 **大模型**；在 `P20`、`P30`、`D10` 中重选 **眼底筛查医学知识库**；点击测试并全部 **发布**。
4. **分别装配两个多智能体控制器**：
   - 在 **智能体管理 → 多智能体** 分别创建 `视健康-患者端管家` 和 `视健康-医生端辅助诊断`，选择 **大模型识别模式**，按上表填入对应子工作流与描述。
   - **重要**：本版工作流均只需单一 `query` 参数，在控制器中不再会触发“多槽位参数提取原子能力调用失败”。
5. **配合拍片室系统与一体化门户演示闭环**：
   - **拍片室影像同步模拟端**：`https://severj.top/v1/imaging_room`（输入手机号建档/回显患者信息，上传左眼或右眼眼底照同步为待分析状态）；
   - **医患双端在线演示门户**：`https://severj.top/v1/demo`（预置 3 位典型模拟患者，支持患者端与医生端现场互动体验与打印双版本 A4 PDF 报告）。
