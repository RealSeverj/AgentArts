# 智果开发草稿迁移

这套模板保留医生版提示词、`screen_fundus` 工具、华为云 MaaS 与 DeepSeek 模型配置，并将原账号的插件密文、供应商凭据记录中的用户标识、旧租户标识和账户存储路径清空。应用、工具、模型之间的资源关联标识和平台内置服务信息保留，用于智果解析依赖关系。原有临时隧道地址已替换为不可解析的占位域名。

## 接入新电脑

1. 先按总说明启动迁移后的推理服务，为该服务配置目标账号可访问的 HTTPS 根地址。确认根地址下的 `/readyz` 返回 `{"ready": true}`。双图链接也需要使用同一可访问的域名。
2. 在本目录运行下例，把示例域名替换为上一步的真实地址。该脚本仅使用 Python 标准库，生成的文件不写入任何密钥。输出目录必须是新目录。

   ```shell
   python prepare_agent.py --origin https://your-inference-domain.example.com --output agent_ready
   ```

3. 在目标账号进入“开发中心 → 智能体管理 → 单智能体 → 导入”，选择 `agent_ready/agent_fundus.jsonl`，勾选应用及其依赖资源。在现有空间中先检查同名资源的覆盖提示，也可以导入到新的项目空间。逐条查看依赖资源的导入状态。
4. 在目标账号配置华为云 MaaS 认证，选用目标账号可调用且支持工具调用的模型。导出的模型为 `deepseek-v4.1-flash-1017`。插件 HTTP Header 名称为 `X-API-Key`，在智果设置中填写新电脑后端正在使用的 API Key。这是两个独立的凭据。
5. 在智果插件调试中调用 `screen_fundus`，再从开发预览上传一张公开眼底照片。确认能看到“主要判读”“阅片意见”，原图和标注图都能打开。临时域名更换后，插件地址和后端用于生成阅片链接的地址都需要同步更新。

## 导入兼容性

此次只做了本地结构核验，未在另一华为云账号实际导入。若目标平台拒绝有空归属字段的模板，或只导入了主应用，可用同一目录已配置域名的 `screen_fundus.openapi.json` 在支持 OpenAPI 的插件创建入口中创建 API 插件，或依据该文件在平台按接口手动创建。需要保留的方法为 `POST /v1/screen_fundus`，操作名为 `screen_fundus`，JSON 正文只含 `image_url`，请求头 `Content-Type` 为 `application/json`。设置鉴权后测试、保存插件版本，替换应用里的旧工具绑定。若需在全新空间手工创建应用，可使用 `医生报告系统提示词.txt` 恢复正文规则，并选择可调用工具的对话模型。

本地检查覆盖四条 JSONL 记录、嵌套 DSL 解析、工具与模型交叉引用、请求路径与方法、两份插件定义中的凭据和域名、医生报告返回字段。迁移包不携带操作账号或可用密钥。
