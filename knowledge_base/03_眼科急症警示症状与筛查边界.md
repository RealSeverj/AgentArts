# 眼科急症警示症状、图像质控与筛查边界

本文档用于支撑高风险症状优先拦截规则（Symptom-first）、图像质量拒识说明以及系统能力边界解答。

---

## [SRC_NEI_RD_URGENT] 1. 必须立即眼科急诊评估的警示症状
依据美国国立眼科研究所（NEI）及眼科临床急诊分诊原则，当患者描述出现以下任意一项症状时，无论眼底彩色照片是否检出异常、甚至尚未拍摄眼底照，均应**优先建议立即眼科急诊或当日尽快专科评估**：
1. **眼前突然出现大量新的“飞蚊”或黑影飘动**（如蜘蛛网、烟雾或黑点突然暴增）；
2. **单眼或双眼出现闪光感**（闭眼或暗处尤为明显，如闪电一闪而过）；
3. **视野中出现像灰色或黑色幕帘一样的遮挡感**（或固定方位的视野缺损）；
4. **突发单眼视力骤降、明显看物模糊变形或突然失明**；
5. **剧烈眼痛伴同侧头痛、恶心呕吐或视物见虹视**（警惕急性闭角型青光眼发作）。

**核心原则**：普通后极部 45° 眼底相机照片对视网膜最周边区域的裂孔或早期周边脱离覆盖有限。因此**“图像未检出异常”绝对不能降低已命中上述症状的就医优先级**。

## [SRC_QC_RETAKE] 2. 图像质量不足（Reject / Usable）的原因与重拍指南
本系统在疾病推理前强制执行 `quality` 质量门控模块：
- **`Good`（质量良好）**：清晰度、曝光、对焦和视野均适合后续辅助判读。
- **`Usable`（可判读但质量受限）**：存在轻度暗角、局部反光或轻度模糊，仍可参考下游结果，但医生与患者需注意局部细节可能受遮挡。
- **`Reject`（质量不足 / 不可判读）**：常见原因包括严重失焦模糊、过曝泛白、过暗欠曝、严重晶状体混浊遮挡、或上传了非眼底照片（如自拍、眼表外眼照、OCT 断层图、化验单截图）。
- **处理原则**：一旦判定为 `Reject`，系统会**强制拦截下游疾病分级与异常筛查模型**，禁止输出正常或阴性结论，并引导用户重新拍摄清晰、无反光、涵盖视盘与黄斑的彩色眼底照。

## [SRC_SCREEN_SCOPE] 3. “未检出异常”的适用范围与就医准备清单
1. **“未检出目标异常”不等于“眼睛完全健康”**：
   - 本系统覆盖的专病与筛查范围为：糖尿病视网膜病变 0~4 级、11 项常见眼底标签（`RVO, LS, DN, AMD, CSR, ODC, ODE, ODP, MYA, TSLN, ABNORMAL`）、五标签筛查及青光眼辅助筛查线索、四类微血管病灶候选区。
   - 本系统不能替代裂隙灯检查、眼压测量、周边散瞳眼底检查或 OCT 断层扫描，也未经过人群真实患病概率校准。
2. **眼科就诊前准备清单**：
   - 携带本次眼底彩色原图、双图报告或过往历次眼底检查档案；
   - 整理既往关键信息：糖尿病/高血压病史及最近一次糖化血红蛋白数值、既往是否做过眼底激光光凝或玻璃体腔注药手术、近视度数及青光眼家族史；
   - 若需散瞳详查眼底，就诊当天建议**不要自行驾车**，并可随身携带墨镜以防强光刺眼。
