# 医学知识库导入华为云 AgentArts（智果）说明

本目录下的 4 份文档专为华为云 AgentArts 平台知识库设计，每个知识条目均带有与后端随访规则服务 `source_ids` 对应的稳定编号（如 `[SRC_DICT_LS]`、`[SRC_DR_GUIDELINE_2024]`、`[SRC_NEI_RD_URGENT]`、`[SRC_EDU_CHECKUP_BENIGN]`）。

## 推荐导入步骤

1. 登录华为云 AgentArts（智果）控制台，进入 **托管与运行 → 知识库 → 创建知识库 → 创建平台知识库**。
2. 知识库名称可设为：`眼底筛查医学知识库`。
3. 上传以下 4 份 Markdown 文档：
   - `01_标签字典与体征边界.md`
   - `02_糖网分期与专病随访依据.md`
   - `03_眼科急症警示症状与筛查边界.md`
   - `04_大众体检与慢病护眼科普.md`
4. **分段与检索推荐设置**：
   - 优先按二级标题（`## `）或 400~600 字符语义分段，确保每个 `[SRC_...]` 条目及其“患者解释 / 下一步建议 / 家属清单”不被拆散。
   - 检索方式推荐：**混合检索（语义 + 关键词）**，`TopK = 5`。
5. **命中测试建议问题**：
   - “玻璃膜疣（DN）是不是就是黄斑变性（AMD）？”（预期命中 `[SRC_DICT_DN_AMD]`）
   - “检出激光瘢痕（LS）是不是新得了眼病？”（预期命中 `[SRC_DICT_LS]`）
   - “最近眼前突然有很多黑影飞蚊还有闪光感，但照片没报错怎么办？”（预期命中 `[SRC_NEI_RD_URGENT]`）
   - “糖网 2 级是什么意思，微动脉瘤和硬性渗出严重吗？”（预期命中 `[SRC_DR_GUIDELINE_2024]`）
   - “单位体检写着豹纹状眼底和视盘凹陷大，是不是快失明了？家里老人有糖尿病陪诊要带什么？”（预期命中 `[SRC_EDU_CHECKUP_BENIGN]`、`[SRC_EDU_CAREGIVER_GUIDE]`）
6. **绑定到智能体**：
   - 在单智能体 `A0` 或多智能体工作流 `A2`、`A3`、`A4` 节点的 **知识库（Knowledge）** 中挂载该知识库，即可在解读与随访问答中引用真实来源编号。
