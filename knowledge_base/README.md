# 医学知识库导入华为云 AgentArts（智果）说明

本目录下的 5 份文档专为华为云 AgentArts 平台知识库设计，兼顾医生临床专业依据与患者通俗科普回答。

## 推荐导入步骤

1. 登录华为云 AgentArts（智果）控制台，进入 **托管与运行 → 知识库 → 创建知识库 → 创建平台知识库**。
2. 知识库名称可设为：`眼底筛查医学知识库`。
3. 上传以下 5 份 Markdown 文档：
   - `01_标签字典与体征边界.md`
   - `02_糖网分期与专病随访依据.md`
   - `03_眼科急症警示症状与筛查边界.md`
   - `04_大众体检与慢病护眼科普.md`
   - `05_常见眼病日常科普问答_患者亲切版.md`（患者端日常问诊与青光眼/糖网/飞蚊症通俗科普）
4. **分段与检索推荐设置**：
   - 优先按二级标题（`## `）或 400~600 字符语义分段，确保每个条目及其日常注意、推荐阅读不被拆散。
   - 检索方式推荐：**混合检索（语义 + 关键词）**，`TopK = 5`。
5. **命中测试建议问题**：
   - “青光眼一般是怎么发生的呀，平常要注意些什么呢？”（预期命中 `[SRC_POP_GLAUCOMA]`）
   - “玻璃膜疣（DN）是不是就是黄斑变性（AMD）？”（预期命中 `[SRC_DICT_DN_AMD]`）
   - “检出激光瘢痕（LS）是不是新得了眼病？”（预期命中 `[SRC_DICT_LS]`）
   - “最近眼前突然有很多黑影飞蚊还有闪光感怎么办？”（预期命中 `[SRC_POP_FLOATERS]`、`[SRC_NEI_RD_URGENT]`）
   - “糖网 2 级是什么意思，平时怎么护眼？”（预期命中 `[SRC_DR_GUIDELINE_2024]`、`[SRC_POP_DR_DAILY]`）
6. **绑定到多智能体工作流**：
   - 在 `P20_结合病史症状问诊`、`P30_眼健康日常科普答疑`、`D10_院内影像辅助诊断` 工作流的 **知识检索** 节点中挂载该知识库。
